# wx-summary

wx-summary 是一个本机运行的微信群消息 AI 摘要工具。它目前主要面向 **Windows / macOS 版微信 4.1.9**，读取本机微信 v4 数据库副本和本地媒体文件，把你选择的群和时间范围整理成完整时间线，再发送给你自己配置的 OpenAI / Anthropic 兼容端点，生成适合发给群成员看的摘要长图。

> 当前已重点适配并用于验证的是 **Windows 版微信 4.1.9** 和 **macOS 版微信 4.1.9**。截至目前，**Windows 版微信 4.1.10 不可用**，需要重新适配数据库结构、媒体索引或 key 提取逻辑。macOS 版微信 4.1.9 可使用 `启动.command` 启动，程序会发现 Mac 微信数据目录，并使用 Keychain 加密保存配置；如果数据库 key 没有被本地缓存自动识别，可以在设置页填写手动数据库 key，或把外部工具导出的 key 放到本地 key 缓存文件中。

## 功能

- Windows 双击 `启动.cmd`，macOS 双击 `启动.command`，即可启动本地服务并自动打开浏览器页面。
- 读取 Windows / macOS 版微信 4.1.9 的本机群列表、文本、引用、图片、文件、视频和语音/音频元信息。
- 图片会尝试从本地微信文件解封后交给多模态模型分析；视频会尽量抽关键帧；语音/音频会尽量转码发送，失败时保留时间、发送人、时长和文件名等元信息。
- 消息、文件、图片、视频、语音都会带时间信息发送给 AI，方便模型理解上下文关联。
- 摘要按完整时间线整理后发送给 AI；小输入一次性发送，大输入会按时间顺序自动分段并发总结再合并，尽量兼顾质量、速度和完整性，不只取前几张图。
- 多选群会按当前电脑配置并行准备数据，谁先准备好谁先进入受控 AI 队列；单个群失败不会静默吞掉。
- 群聊和单聊展示微信昵称，不使用本机备注作为摘要称呼。
- 重要网页链接会抓取可访问页面内容；支持 Responses `web_search_preview` 的 OpenAI 兼容端点还会让 AI 联网核查并补充来源摘要。
- 历史页支持查看、下载、复制、在文件夹中显示、重新渲染已生成长图；重新渲染不重新调用 AI。
- API Key 和手动微信数据库 key 会加密保存在本机当前用户下：Windows 使用 DPAPI，macOS 使用 Keychain。

## 运行环境

- Windows 10/11 或 macOS
- Node.js 20+
- Windows / macOS 版微信 4.1.9，本机存在可读取的微信数据目录
- Windows 版微信 4.1.10 截至目前不可用，请先不要升级到该版本用于本工具
- macOS 版微信 4.1.9 如自动读取失败，需要准备有效数据库 key；历史缩略图、服务端重新渲染和复制 PNG 到系统剪贴板当前仍只支持 Windows
- 一个 OpenAI / Anthropic 兼容的模型接口

## 启动

Windows：

```powershell
启动.cmd
```

首次启动会自动执行 `npm ci` 安装依赖。启动后服务只监听 `127.0.0.1`，浏览器页面通过一次性本机会话 token 访问 API。右键托盘图标选择“退出”会停止后端进程并清理临时文件。

开发调试：

```powershell
npm ci
npm run dev
```

macOS 可双击 `启动.command` 或在终端运行：

```bash
./启动.command
```

注意：macOS 版微信 4.1.9 可以使用。程序会尝试发现 `xwechat_files` 数据目录，并使用 macOS Keychain 加密保存配置；如自动读取失败，需要在设置页填写手动 key，或把外部工具导出的 key 放到本地 key 缓存文件中。历史缩略图、服务端重新渲染和复制 PNG 到系统剪贴板当前仍只支持 Windows；正常生成摘要长图使用浏览器 canvas 保存，不依赖这些 Windows-only 能力。

## 配置文件

仓库不提交本机配置文件。首次启动时如果没有 `data/settings.json`，程序会使用内置默认配置进入设置向导；保存设置后会在本机自动生成：

```text
data/settings.json
data/secrets.bin
data/cursors.json
outputs/
```

`data/settings.json` 保存普通设置；API Key 和微信手动 key 会加密保存到 `data/secrets.bin`，不会写入 `settings.json`。
摘要长图、历史索引和摘要 JSON 只允许保存在 `outputs/` 目录下，避免混入源码目录被误提交。

## 隐私边界

不要提交这些本地运行数据：

- `data/settings.json`
- `data/secrets.bin`
- `data/cursors.json`
- `data/*weixin*baseline*.json`
- `outputs/`
- `node_modules/`
- `docs/验收记录.md` 等本机验收材料
- 本机微信数据库、解密副本、图片、语音、视频、`.dat`、`.wxgf`
- 真实 API Key、手动数据库 key、本机路径、群 ID、群成员名单、聊天内容

`.gitignore` 已默认忽略上述路径和常见运行产物。公开仓库只保留 `data/settings.example.json` 作为示例配置。
如果要发布源码包，请使用干净 clone 或 `git archive HEAD`；不要直接压缩当前工作目录，避免把本机 `data/`、`outputs/`、`node_modules/`、`.git/` 一起带出去。

程序的数据读取边界：

- 聊天内容、群成员昵称、文件名、图片/视频/语音元信息来自本机微信数据库副本或本地文件。
- 内存扫描只用只读权限寻找解密所需 key 候选，不从内存提取聊天内容或图片内容。
- 外部明文本地 key 缓存同样敏感；优先在设置页填写手动 key，让程序加密保存到 `data/secrets.bin`。
- 真实读取失败会报错，不会用演示数据伪装成真实摘要。
- 摘要发送给 AI 前会按设置对手机号、身份证号、银行卡号等做脱敏。
- 你选择的聊天内容和媒体分析输入会发送到你配置的 AI 端点；请确认端点和模型供应商符合你的隐私要求。
