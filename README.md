# wx-summary

wx-summary 是一个本机运行的微信群消息 AI 摘要工具。它目前主要面向 **Windows 版微信 v4** 和 **macOS 版微信 4.1.9**，读取本机微信 v4 数据库副本和本地媒体文件，把你选择的群和时间范围整理成完整时间线，再发送给你自己配置的 OpenAI / Anthropic 兼容端点，生成适合发给群成员看的摘要长图。

> 当前重点适配 **Windows 版微信 v4** 和 **macOS 版微信 4.1.9**。Windows 会尽力自动识别数据库密钥，失败时可在设置页填写手动密钥；macOS 需要手动密钥。API Key 和手动数据库密钥加密保存在 `data/secrets.bin`，自动验证成功的数据库密钥候选保存在 `data/wxdb-keys.bin`。

## 功能

- Windows 双击 `启动.cmd`，macOS 双击 `启动.command`，即可启动本地服务并自动打开浏览器页面。
- 按项目副本读取 Windows / macOS 版微信 4.1.9 的本机群列表、文本、引用和数据库里的媒体元信息；图片、文件、视频和语音/音频内容按需从本地微信媒体文件只读复制到项目临时副本后处理；macOS 需手动密钥 + 自动项目副本，并在目标 Mac 上验证实际环境。
- 图片会尝试从本地微信文件解封后交给多模态模型分析；视频会尽量抽关键帧；语音/音频会尽量转码发送，失败时保留时间、发送人、时长和文件名等元信息。
- 消息、文件、图片、视频、语音都会带时间信息发送给 AI，方便模型理解上下文关联。
- 摘要按完整时间线整理后发送给 AI；小输入一次性发送，大输入会按时间顺序自动分段并发总结再合并，尽量兼顾质量、速度和完整性，不只取前几张图。
- 多选群会按当前电脑配置并行准备数据，谁先准备好谁先进入受控 AI 队列；单个群失败不会静默吞掉。
- 群聊和单聊展示微信昵称，不使用本机备注作为摘要称呼。
- 重要网页链接会抓取可访问页面内容；支持 Responses `web_search_preview` 的 OpenAI 兼容端点还会让 AI 联网核查并补充来源摘要。
- 历史页支持查看、下载、复制、在文件夹中显示和不重调 AI 的历史重渲染；重渲染使用当前浏览器 Canvas 生成并展示最终 PNG，再由本地服务校验历史版本后另存。
- API Key 和手动微信数据库 key 会加密保存到 `data/secrets.bin`；自动验证成功、可跨数据库副本复用的 key 候选会按账号指纹写入 `data/wxdb-keys.bin` 加密缓存，避免服务重启后反复扫描。Windows 使用 DPAPI，macOS 使用 Keychain 中的 `wx-summary.secrets` 包装密钥保护这两个密文文件。

## 运行环境

### 通用要求

- Node.js 20+
- OpenAI / Anthropic 兼容的模型接口
- 本机存在可读取的微信 v4 数据目录

### Windows

- Windows 10/11
- Windows 版微信 v4；4.1.9 有历史完整链路证据，当前本机 4.1.10.27 已有自动 key/db 运行态验证
- 尽力支持只读内存扫描自动密钥提取；微信版本、账号目录或同步状态变化后仍会自动复核，失败时需填写或粘贴有效手动密钥候选
- Windows 4.1.9 已覆盖托盘、服务端重渲染、历史缩略图和系统剪贴板复制；其他微信 v4 版本会在读取前重新验证数据库与密钥

### macOS

- macOS 13+（Ventura / Sonoma / Sequoia / Tahoe 26 或更新的正式版）
- macOS 版微信 4.1.9
- macOS 需要手动填写数据库密钥 key；数据库副本不需要手动配置，首次刷新群列表、生成长图、生成文本预览或验证数据库时会自动准备/刷新 `data/wxdb-mirror` 项目副本
- 核心流程已实现，实际可用性取决于微信版本、数据库密钥、文件权限和浏览器能力

## 启动

### Windows

双击 `启动.cmd`：

```powershell
启动.cmd
```

首次启动会自动执行 `npm ci` 安装依赖。启动后服务默认监听
`127.0.0.1:7788`，端口被占用时会顺延，浏览器自动打开实际服务 URL；
浏览器页面通过一次性本机会话 token 访问 API。右键托盘图标选择“退出”
会停止后端进程并清理临时文件。

### macOS

双击 `启动.command`，或在终端运行：

```bash
./启动.command
```

服务在 Terminal 窗口运行，浏览器会自动打开实际服务 URL；默认是
`http://127.0.0.1:7788`，端口被占用时会顺延，按 Terminal 输出为准。
`Ctrl+C` 或关闭窗口退出。macOS 需要手动填写数据库密钥，请参考
[macOS 使用指南](docs/macOS使用指南.md)。

### 开发调试（双平台）

```bash
npm ci
npm run dev  # 启动但不自动打开浏览器
```

## 配置文件

仓库不提交本机配置文件。首次启动时如果没有 `data/settings.json`，程序会使用内置默认配置进入设置向导；保存设置后会在本机自动生成：

```text
data/settings.json
data/secrets.bin
data/wxdb-keys.bin
data/cursors.json
outputs/
```

`data/settings.json` 保存普通设置；API Key 和微信手动 key 会加密保存到 `data/secrets.bin`，自动验证成功的微信数据库 key 候选会按账号指纹保存到 `data/wxdb-keys.bin`，都不会写入 `settings.json`。`data/wxdb-keys.bin` 只保存严格校验后的可移植候选，用于重启后的快速复核；账号来源变化或候选失效时仍会重新验证。macOS 下 Keychain 只保存 `wx-summary.secrets` 包装密钥材料；实际 API Key 和手动 key 仍在 `data/secrets.bin`，自动验证候选在 `data/wxdb-keys.bin`，两者都是 AES-GCM 加密包。
摘要长图、历史索引和摘要 JSON 只允许保存在 `outputs/` 目录下，避免混入源码目录被误提交。

## 隐私边界

不要提交这些本地运行数据：

- `data/settings.json`
- `data/secrets.bin`
- `data/wxdb-keys.bin`
- `data/cursors.json`
- `data/*weixin*baseline*.json`
- `outputs/`
- `node_modules/`
- `docs/assets/` 和未脱敏的真机验收截图、原始诊断包、外部验收附件
- 本机微信数据库、解密副本、图片、语音、视频、`.dat`、`.wxgf`
- 真实 API Key、手动数据库 key、本机路径、群 ID、群成员名单、聊天内容

`.gitignore` 默认忽略运行数据、内部计划、验收过程材料、截图和诊断附件。公开仓库只保留源码、测试、安全配置、启动/依赖工具、`data/settings.example.json`、README 和使用文档。
如果要发布源码包，请使用干净 clone 或 `git archive HEAD`；不要直接压缩当前工作目录，避免把本机 `data/`、`outputs/`、`node_modules/`、`.git/` 一起带出去。

程序的数据读取边界：

- 聊天内容、群成员昵称、文件名和图片/视频/语音元信息来自本机微信数据库项目副本；图片、视频、语音/音频正文内容在需要交给 AI 前，会从本机微信媒体文件只读定位并复制到 `outputs/.tmp/media` 项目临时副本后处理。
- 数据库副本不需要手动配置；首次刷新真实群、生成长图、生成文本预览或验证数据库时，程序会按需自动把源数据库复制/刷新到 `data/wxdb-mirror` 项目副本。数据库源库只复制、不查询/解密：程序只读取源数据库普通文件的路径、大小、修改时间和文件身份等元数据，并调用系统文件复制；不会对源库内容计算 SHA256，也不会在源库路径上打开、解析、查询或解密数据库。SHA256 只用于校验已经复制到项目内的 DB/WAL 文件（SHM 不持久复制）。只有当源库可见、源库元数据快照未变化、项目副本 DB/WAL 文件集合完全一致，且每个项目副本都是普通文件、大小和项目副本内容哈希都匹配时才复用；否则自动用 staging 重新复制并覆盖旧项目副本。复制前后还会重新检查源文件元数据，源文件在复制期间变化就放弃本次副本并自动重试。若源库不可见，程序会拒绝复用旧项目副本，避免用过期副本生成“看似成功”的结果。群列表、摘要和数据库验证的数据库查询/解密只操作项目副本，并在打开 SQLCipher 前再复制到 `outputs/.tmp/db` 临时工作副本；媒体内容读取按上一条的本地媒体文件边界执行。副本没有手动配置或导入入口；连续失败时回到生成、生成文本预览或刷新群列表的进度卡点击“重试自动准备副本”，程序会重新按源库元数据快照判断复用、复制或覆盖。
- 内存扫描只用只读权限寻找解密所需 key 候选，不从内存提取聊天内容或图片内容。
- 外部明文本地 key 缓存同样敏感；优先在设置页填写手动 key，让程序加密保存到 `data/secrets.bin`。程序验证成功后还会把可复用候选写入按账号指纹隔离的 `data/wxdb-keys.bin` 加密缓存，以避免每次重启重新扫描；彻底清理本机数据库 key 材料时需要同时删除这两个加密文件。
- macOS 下只复制 `data/secrets.bin` 不能跨机器或跨用户解密；它依赖当前用户 Keychain 中的 `wx-summary.secrets` 包装密钥。
- 真实读取失败会报错，不会用演示数据伪装成真实摘要。
- 摘要发送给 AI 前会按设置对手机号、身份证号、银行卡号等做脱敏。
- 你选择的聊天内容和媒体分析输入会发送到你配置的 AI 端点；请确认端点和模型供应商符合你的隐私要求。

## 已知限制

### Windows

- 微信版本、账号目录或同步状态变化后，自动 key/db 验证可能重新失效；程序会在读取前自动复核项目副本和 key，失败时提示填写有效手动密钥，而不是继续使用过期副本伪造成功。

### macOS

- 自动密钥提取未适配，必须手动填写数据库密钥。
- 后台服务端 PNG 不可用；页面手动历史重渲染仍可使用浏览器 Canvas。若浏览器不能创建 PNG，请回到总结页缩短内容或改用“生成文本预览”。
- 历史缩略图走 Node 便携 PNG 路径；点击历史记录仍可查看完整原图。
- 系统剪贴板图片复制兜底不可用；浏览器图片剪贴板是否可用取决于浏览器和权限，稳定方案是使用“下载 PNG”保存文件后再分享。
- 无系统托盘，服务生命周期由 Terminal 窗口控制。

macOS 的安装、密钥配置和平台限制详见 [macOS 使用指南](docs/macOS使用指南.md)。
