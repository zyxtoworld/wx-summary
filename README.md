# wx-summary

本机运行的微信群消息 AI 摘要工具。它读取你本机微信的数据副本，按群和时间范围整理完整时间线，调用你配置的 OpenAI / Anthropic 兼容端点，生成可预览、下载和分享的摘要长图。

> 当前重点支持 Windows 版微信 v4，以及 macOS 版微信 4.1.9。Windows 会尽力自动识别数据库密钥；macOS 需要在设置页填写手动密钥。

## 能做什么

- 选择一个或多个群、时间范围和过滤条件，生成摘要长图或文本预览。
- 保留消息时间、发送人、引用关系、文件信息和可用的媒体元信息，让 AI 按完整时间线理解上下文。
- 按需处理本地图片、视频、语音和音频；无法读取正文时保留时间、发送人、时长和文件名等元信息，不伪造内容。
- 重要链接先由本地服务抓取可访问页面；兼容 Responses `web_search` 和 `web_search_preview` 的端点还可以让 AI 联网核查，程序会自动探测可用工具名。
- 历史页支持搜索、查看、下载、复制、在文件夹中显示和重新渲染。重新渲染只使用已保存的摘要，不会再次调用 AI。
- 可选启用定时摘要；单个群失败不会中断整轮任务。
- API Key、手动数据库密钥和已验证的密钥候选均以加密文件保存，不写入普通设置 JSON。

## 平台功能对照

| 平台 | 状态 | 关键差异 |
| --- | --- | --- |
| Windows 10/11 + 微信 v4 | 主要支持 | Node.js 20+；支持只读自动密钥扫描、系统托盘、服务端 PNG 和 Windows 剪贴板兜底。当前本机 4.1.10.27 已有自动 key/db 运行态验证；微信版本、账号目录或同步状态变化后仍会自动复核，失败时需填写或粘贴有效手动密钥候选。 |
| macOS 13+ + 微信 4.1.9 | 已实现路径，需目标 Mac 真机确认 | Node.js 20+；必须手动填写数据库密钥；没有系统托盘、服务端 PNG 和系统剪贴板图片兜底，页面长图使用浏览器 Canvas。 |

macOS 的安装、密钥和平台限制见 [macOS 使用指南](docs/macOS使用指南.md)。完整的页面操作说明见 [用户手册](docs/用户手册.md)。

## 快速开始

### Windows

1. 安装 Node.js 20 或更高版本。
2. 双击项目根目录的 `启动.cmd`：

   ```text
   启动.cmd
   ```

   启动器会检查依赖，随后启动本地服务和托盘。默认地址为 `http://127.0.0.1:7788`；端口被占用时会自动顺延，按浏览器或托盘打开的实际地址为准。
3. 首次进入网页时完成 AI 接口、模型、微信检测和群白名单设置。

如果只想在当前窗口查看日志，可运行：

```powershell
启动.cmd --console
```

`验收-记录微信哈希.cmd` 是可选的启动前 A3 外部二进制基线记录脚本，只写入 `data/external-weixin-binary-baseline.json`，不是程序运行依赖。普通使用直接运行 `启动.cmd` 即可。

### macOS

1. 安装 Node.js 20 或更高版本。
2. 在 Terminal 中进入项目根目录并运行：

   ```bash
   chmod +x 启动.command
   ./启动.command
   ```

   首次启动会自动安装缺少的依赖。服务默认监听 `http://127.0.0.1:7788`，端口被占用时会顺延；按 Terminal 输出的实际 URL 访问。按 `Ctrl+C` 退出服务。
3. 在设置页保存当前微信账号的手动数据库密钥，再刷新群列表。

### 开发调试

```bash
npm ci
npm run dev
```

`npm run dev` 启动服务但不自动打开浏览器。

## 首次配置

向导会依次完成以下设置：

1. 选择 `OpenAI` 或 `Anthropic` 兼容提供方。
2. 填写 Base URL、API Key，获取并选择模型。
3. 检查微信账号和本地数据状态。
4. 设置群白名单；留空表示不限制群选择。

Windows 会尽力扫描微信进程中的数据库密钥候选；扫描失败或账号状态变化时，在设置页填写手动密钥。macOS 当前必须手动填写。支持 64/96/128/160/192 位十六进制候选，以及向导提示的导出片段格式；多个候选请逐行粘贴。

程序会自动把微信数据库复制到项目内的 `data/wxdb-mirror`，后续查询和解密只操作项目副本及 `outputs/.tmp/db` 临时副本，不需要手动配置数据库路径。源数据库不可见或复制校验不通过时，程序会拒绝复用过期副本并提示重试。

## 生成和查看摘要

1. 在“总结”页选择群和时间范围，例如“今天”“最近 24h”或自定义范围。
2. 按需设置发送人、关键词、消息类型等过滤条件。
3. 点击“生成长图”或“生成文本预览”。多选群会分别生成并保存，页面预览最后完成的一张。
4. 在结果页下载 PNG、复制图片或查看文件位置；文本预览需要文件时，再点击“导出 MD”。
5. 在“历史”页搜索并打开已保存结果。历史重渲染使用浏览器 Canvas 生成最终 PNG，保存前会由本地服务校验版本，原始文件保留。

发送给 AI 的内容只包含你选择的群和时间窗。图片、视频、语音或音频正文只有在设置允许且本机文件可读时才会作为媒体输入；否则保留消息元信息继续总结。

## 链接检索和 AI 查链

链接处理分两层：

- 本地预览：服务尝试跟随跳转，读取可访问页面的标题、描述和正文片段。
- AI 查链：当兼容端点支持 Responses `web_search` 或 `web_search_preview` 时，程序会自动探测并复用可用工具；不支持、网络受限、页面需要登录或返回错误时，会退回本地页面内容、URL、标题和上下文。

因此“AI 查链 0/x”表示 x 个链接没有得到 AI 联网结果，不等于摘要流程一定失败；结果仍可能来自本地页面抓取。登录墙、验证码和强 JS 页面无法保证抓取成功。

## 数据与隐私边界

- 服务默认只监听 `127.0.0.1`，不提供协议登录、自动发消息或 UI 自动化。
- 聊天内容、群成员昵称、文件名和媒体元信息来自微信数据库项目副本；源数据库只作为复制来源，不在源路径上查询、解密或计算内容哈希。
- 摘要发送到你配置的 AI 端点前，会按设置对手机号、身份证号和银行卡号等字段脱敏；是否发送媒体正文由隐私设置控制。
- API Key 和手动数据库密钥保存在 `data/secrets.bin` 加密包；自动验证成功的候选保存在 `data/wxdb-keys.bin` 加密缓存。Windows 使用 DPAPI，macOS 使用 Keychain 条目 `wx-summary.secrets` 保护本机包装密钥。
- 普通设置保存在 `data/settings.json`；摘要、历史索引、临时数据库和日志保存在 `outputs/`。
- `.gitignore` 默认忽略 `data/` 运行数据、`outputs/`、数据库、媒体、日志、密钥、`docs/assets/`、内部计划和验收附件。不要提交真实 API Key、数据库密钥、微信数据库、聊天内容或未脱敏截图。

完整的数据复制、密钥缓存和清理说明见 [用户手册](docs/用户手册.md) 与 [macOS 使用指南](docs/macOS使用指南.md)。

## 配置文件

公开配置模板为 [`data/settings.example.json`](data/settings.example.json)。首次启动后程序会在本机生成：

```text
data/settings.json        # 普通设置
data/secrets.bin          # 加密 API Key / 手动密钥
data/wxdb-keys.bin        # 加密的已验证密钥候选
data/wxdb-mirror/         # 微信项目副本
outputs/digests/          # PNG 与历史摘要
outputs/previews/         # 导出的 Markdown 预览
outputs/.tmp/             # 临时文件与脱敏日志
```

不要直接压缩当前工作目录发布源码；使用干净 clone 或 `git archive HEAD`，避免带出本机运行数据和 `.git`。

## 常见故障

| 现象 | 原因与处理 |
| --- | --- |
| 启动失败或提示找不到 Node.js | 安装 Node.js 20+；Windows 重新运行 `启动.cmd`，macOS 先在 Terminal 执行 `node --version` 和 `./启动.command` 查看原始错误。 |
| 提示“需要手动密钥” | Windows 自动扫描未通过，或 macOS 当前平台必须手动配置；确认密钥属于右上角选中的微信账号，并把多个候选逐行粘贴。 |
| 群列表为空或项目副本失败 | 保持微信运行，刷新群列表；按进度卡提示重试自动准备副本。源库不可见、账号切换或文件正在写入时不要继续使用旧副本。 |
| `AI 查链 0/x` | 当前端点不支持联网工具、网络受限或页面不可访问；检查本地页面预览和 AI Base URL，摘要仍可使用消息上下文生成。 |
| `ai_quality_failed` | AI 返回了空洞或与消息数量不符的成品，质量保护因此拒绝保存；缩短时间范围、检查模型或稍后重试。 |
| PNG 复制失败 | 浏览器权限或平台能力不允许图片剪贴板；先下载 PNG。Windows 有系统剪贴板兜底，macOS 没有。 |
| 页面打不开 | 确认服务进程仍在运行，并使用启动器输出的实际端口；开发调试可运行 `npm run dev` 查看日志。 |
