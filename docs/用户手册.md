# wx-summary 用户手册

## 启动

Windows 双击项目根目录的 `启动.cmd`。macOS 双击 `启动.command`，如果系统提示没有执行权限，可在 Terminal 里运行 `chmod +x 启动.command` 后再启动。首次安装依赖时会短暂显示安装窗口或 Terminal 输出；安装完成后，浏览器会打开 `http://127.0.0.1:7788`。如果端口被占用，程序会自动顺延到下一个端口。

Windows 启动后可以在系统托盘里找到 `wx-summary` 图标：右键“打开网页”可重新打开本地页面，右键“退出”会让后端先清理临时文件再停止服务。macOS 由启动服务的 Terminal 窗口控制生命周期，关闭浏览器标签页不会退出后端。

## 首次设置

首次进入会看到 4 步向导：

1. 阅读安全说明。
2. 选择 `OpenAI` 或 `Anthropic`，填写 Base URL 和 API Key，点击“获取模型”，再选择模型。
3. 查看微信检测结果。当前版本能识别微信进程与数据库目录，并优先读取本机群列表、文本、引用、图片、文件、视频和语音/音频元信息。
4. 选择群白名单，可留空。

API Key 保存后只显示末四位，完整密钥写入 `data/secrets.bin` 加密包；手动数据库密钥也写入同一加密包，不写入普通设置文件。程序自动验证成功的数据库密钥候选会按账号指纹写入独立的 `data/wxdb-keys.bin` 加密缓存，用于服务重启后的快速复核，避免重新扫描每个数据库；候选失效时仍会重新验证。Windows 使用 DPAPI 保护这两个密文文件；macOS 使用 Keychain 条目 `wx-summary.secrets` 作为本机包装密钥。如果换了系统用户、Keychain 条目缺失或密钥文件无法被当前用户解密，旧密文不会展示，也不会上传。

## 数据读取边界

聊天消息、群成员昵称、文件名、时间线和图片/视频/语音元信息来自项目内微信数据库副本；图片、视频、语音/音频正文内容会按需从本机微信媒体文件只读定位并复制到 `outputs/.tmp/media` 项目临时副本后处理。首次刷新真实群、生成长图、生成文本预览或验证数据库时，程序会自动把当前账号 `db_storage` 复制/刷新到 `data/wxdb-mirror`。数据库源库只调用系统文件复制，不扫描、查询或解密。源库阶段只读取普通文件的路径、大小、修改时间和文件身份等元数据；不会对源库内容计算 SHA256，也不会打开、扫描、解析、查询或解密源数据库。SHA256 只用于校验项目内 DB/WAL 副本（SHM 不持久复制）。只有当源库可见、源库元数据快照未变化、项目副本 DB/WAL 文件集合完全一致，且每个项目副本都是普通文件、大小和项目副本内容哈希都匹配时才复用；否则自动用 staging 重新复制并覆盖旧项目副本。复制前后会重新检查源文件元数据，源文件在复制期间变化就放弃本次副本并自动重试。若源库不可见，程序会拒绝复用旧项目副本，避免用过期副本生成“看似成功”的结果。后续群列表、摘要和数据库验证的数据库查询/解密只读取 `data/wxdb-mirror`，并在打开 SQLCipher 前再复制到 `outputs/.tmp/db` 临时工作副本，媒体内容读取按前述本地媒体文件边界执行，副本账号段使用 `wxacc_<hash>` 脱敏标识。副本没有手动配置或导入入口；连续失败时回到生成、生成文本预览或刷新群列表的进度卡点击“重试自动准备副本”，程序会重新按源库元数据快照判断复用、复制或覆盖。Windows 只在需要解密时用只读权限扫描微信进程内存里的 key 候选，不从内存提取聊天内容或图片内容；验证成功的可复用候选会写入 `data/wxdb-keys.bin` 加密缓存并在下次启动时优先复核。macOS 当前不做微信进程内存自动密钥提取，需要在向导或设置页填写手动数据库 key；成功读取后同样会使用加密缓存减少重复验证。真实微信群读取失败会直接报错，不会回落成演示数据。彻底清理本机数据库密钥材料时，需要同时删除 `data/secrets.bin` 和 `data/wxdb-keys.bin`；macOS 还需按指南处理 Keychain 包装密钥。

## 生成摘要

进入“总结”页，选择一个或多个群、时间范围、可选过滤项，然后点击“生成长图”。时间范围提供今天、昨天、昨天+今天、最近 4h、最近 12h、最近 24h、本周七个快捷按钮；自定义时间范围通过日期时间选择器点选，不需要手填字符串。多选群会按顺序逐个生成并保存，预览区显示最后完成的一张，历史页能看到全部结果。最近生成过的 5 个群会自动置顶并显示星标；设置页白名单之外的群仍然可选，只是颜色更淡，避免误以为被隐藏。发送给 AI 的内容按完整时间线整合，图片紧跟对应消息行，文件消息包含时间、发送人和文件名。程序默认把完整时间线一次性发送给 AI；如果端点因上下文或请求体过大失败，才自动分段并再合并总结，已解出的图片不会只取前几张。生成完成后可以下载 PNG、复制到剪贴板，或在文件夹中显示；浏览器拒绝图片剪贴板权限时，Windows 可改由本机后端写入系统剪贴板，macOS 没有系统剪贴板兜底，稳定替代方案是下载 PNG。点击长图可按 1080px 宽查看细节。

如果生成失败，进度卡片会留在页面上并显示错误摘要；点“查看日志”可以展开最近的脱敏运行日志，便于判断是微信读取、AI 端点还是保存长图出了问题。

常见引用消息会带上当前回复和被引用的原文，便于 AI 理解“这句话是在回复谁、回复什么”。

摘要是给群内所有成员看的公共纪要，不会单独输出 `@我` 栏目。重要链接会先由本地服务打开、跟随跳转，抓取可访问页面的标题、描述、正文片段和同站关键页面；OpenAI 兼容端点支持 Responses `web_search_preview` 时，还会额外让 AI 联网核查并补充来源摘要。需要登录、权限受限、AI 搜索拿不到或代理返回 502 的链接，会退回使用本地抓到的页面内容、群消息标题、URL 和上下文判断。

图片会优先通过微信 `hardlink.db` 定位并解封；如果本地索引缺记录，会做限时兜底搜索，避免单张异常图片拖住整次总结。视频会尽量定位本地文件并抽取关键帧作为图片交给 AI；语音和音频文件会尝试定位本地真实文件，能转成 wav/mp3 时作为音频附件发送，接口或本机环境不支持时会自动保留时间、发送人、时长、文件名等元信息继续总结，不会假装听过内容。兜底失败时仍会保留该媒体消息的时间、发送人和元信息给 AI。

“生成文本预览”会走同一套 AI 总结管线，但不保存 PNG，适合快速检查摘要内容。程序只把结果显示在页面；需要文件时，点击文本预览区的“导出 MD”才会把当前脱敏内容写入 `outputs/previews/`。

## 历史与设置

“历史”页默认每页展示 50 条摘要，可继续加载更多；搜索走服务端完整历史索引，不只过滤当前页。点击卡片可查看大图；再点击大图可按 1080px 宽查看细节。弹窗提供下载、复制到剪贴板、在文件夹中显示和不重调 AI 的重新渲染。页面历史重渲染在 Windows 与 macOS 都使用浏览器 Canvas：先展示最终 PNG 预览，保存时由本地服务校验历史版本并另存新版本，原始 PNG 保留；macOS 完整闭环仍需真机验收。后台定时任务使用的服务端 PowerShell PNG 是另一条仅 Windows 可用的链路，不影响页面历史重渲染。“在文件夹中显示”会请求系统文件管理器打开目标位置；Windows 会尽量选中并验证 Explorer，macOS 会请求 Finder `open -R`，Finder 可见、目标 PNG 选中、窗口置前以真机人工确认为准。重新渲染只使用已保存的摘要 JSON，不会重新调用 AI，也不会保存原始聊天时间线。

“设置”页可以修改模型、输出目录、隐私脱敏、白名单和渲染选项。输出目录必须位于项目根目录下。温度、超时、最大字符、最大消息数、图片分段体积、链接数量等内部阈值不再作为普通设置暴露；程序会自动全量优先、失败分段。导出的诊断包会包含日志尾部、Weixin.exe 启动入口托盘前/托盘启动 Node 前/服务启动/当前 SHA256 对照，以及 ffmpeg/微信媒体解码 DLL 可用性，便于核查工具没有修改微信二进制，也便于判断视频关键帧或音频转码是否走了真实处理。
设置页的“验收证据”卡片会显示 A3/A6/B7/B8/D5 的软件证据状态，也可以导出 Markdown 作为人工核对记录。诊断包包含同样的 `acceptance_manual_checks` 和 `local_action_evidence`。每个仍需人工确认的检查项会保持 `status=needs_user_confirmation`，并给出软件侧证据摘要和下一步操作；macOS 的 Finder、剪贴板和长图能力应在实际设备上按 [macOS 使用指南](macOS使用指南.md) 核对。

做 A3 完整验收时，先退出 wx-summary，双击项目根目录的 `验收-记录微信哈希.cmd`，看到它写入 `data\external-weixin-binary-baseline.json` 后，再双击 `启动.cmd` 启动。设置页“验收证据”里如果显示 `external_baseline_matched`，说明外部基线、服务启动后哈希和当前哈希一致；仍需人工确认这份外部基线确实是在启动前生成。
保存 AI 接入设置时，后端会顺手探测一次模型列表；如果端点暂时不可达、返回 401/429 或代理报错，设置仍会保存，页面会用黄色状态提示这次探测失败。
点击“获取模型”会把端点返回的模型列表记到本机设置里。若你保留了一个列表里没有的模型，页面会要求再点一次保存确认，或改成“自定义”模型，避免误把模型切成列表第一个。

“群与调度”里可以配置定时摘要的开关、检查间隔、摘要窗口、最低消息数，以及单群关键词/最低消息数覆盖。检查间隔和摘要窗口用数字加单位下拉选择，不需要手填 `30m`、`4h` 这类格式。启用后，后台循环会遍历已检测到的微信账号，按白名单群定时检查，达到最低消息数且游标有新变化时生成摘要 PNG 并保存到历史；单个群失败不会中断整轮检查。也可以点“立即检查一次”手动触发一轮。
